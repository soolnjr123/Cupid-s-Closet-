# Cupid's Closet

## Descripción del proyecto

Cupid's Closet es una aplicación web orientada a tiendas de ropa femenina. Su objetivo es ofrecer una tienda online organizada, personalizable e interactiva, donde los clientes puedan encontrar prendas y armar outfits de acuerdo con sus preferencias.

## Problema que resuelve

Muchos emprendimientos y tiendas de ropa utilizan solamente redes sociales para mostrar y vender sus productos. Esto puede dificultar la organización del catálogo, la búsqueda de prendas, la visualización de precios y la realización de pedidos.

## Solución propuesta

Cupid's Closet propone una plataforma web que permita organizar los productos de una tienda de ropa en un catálogo digital. Los usuarios podrán visualizar prendas, buscarlas, filtrarlas, agregarlas al carrito y utilizar una función llamada "Encontrá tu outfit", que permitirá buscar combinaciones según ocasión, estilo y presupuesto.

## Usuarios destinatarios

El sistema tendrá principalmente dos tipos de usuarios.

Cliente: podrá visualizar productos, utilizar filtros, buscar prendas, agregar productos al carrito y utilizar la función "Encontrá tu outfit".

Administrador: podrá gestionar los productos de la tienda, modificando información como nombre, precio, categoría y stock.

## Funcionalidades

Las funcionalidades principales serán la visualización del catálogo de productos, búsqueda y filtrado de prendas, visualización de información y precios, carrito de compras con cálculo del total, herramienta "Encontrá tu outfit", registro de pedidos y administración de productos.

## Tecnologías a utilizar

Frontend: HTML, CSS y JavaScript.

Backend: Node.js y Express.

Base de datos: SQLite.

Comunicación entre frontend y backend: API REST utilizando Fetch API.

## Alcance del proyecto

Cupid's Closet incluirá un catálogo de productos, filtros, carrito de compras, cálculo de precios, recomendaciones de outfits, almacenamiento de productos, registro de pedidos y un panel básico de administración.

En esta primera versión no se incluirán pagos reales mediante Mercado Pago, sistemas reales de envío, facturación electrónica ni una aplicación móvil.
