# Primer comité - Cupid's Closet

**Proyecto:** Cupid's Closet  
**Curso:** 7° TecIPP  
**Fecha:** 02/10/2026  
**Asignatura:** Proyecto, Diseño e Implementación de Sistemas Computacionales

## 1. Problema identificado

Muchos emprendimientos de ropa femenina dependen de redes sociales para mostrar productos y recibir pedidos. Esto dificulta mantener el catálogo ordenado, buscar prendas, consultar precios y stock, y organizar pedidos.

## 2. Solución propuesta

Desarrollar una aplicación web llamada **Cupid's Closet** que permita a una tienda de ropa femenina tener un catálogo digital organizado, un carrito de compras y una función especial llamada **“Encontrá tu outfit”**, que ayude al cliente a elegir prendas según ocasión, estilo y presupuesto.

## 3. Usuarios del sistema

### Cliente
- Visualiza productos.
- Busca y filtra prendas.
- Consulta precios e información.
- Agrega productos al carrito.
- Usa “Encontrá tu outfit”.
- Registra un pedido.

### Administrador
- Agrega productos.
- Modifica productos.
- Elimina productos.
- Administra precio, categoría y stock.

## 4. Funcionalidades mínimas

1. Mostrar catálogo de productos.
2. Buscar productos por nombre.
3. Filtrar productos por categoría.
4. Mostrar detalle y precio.
5. Agregar y quitar productos del carrito.
6. Calcular el total de la compra.
7. Recomendar outfits según preferencias.
8. Registrar pedidos.
9. Gestionar productos desde administración.

## 5. Tecnologías previstas

- HTML
- CSS
- JavaScript
- Node.js
- Express
- SQLite
- API REST
- Fetch API
- Git y GitHub

## 6. Alcance de la primera versión

La primera versión incluirá catálogo, filtros, carrito, recomendaciones de outfits, pedidos y administración básica.

No incluirá pagos reales, envíos reales, facturación electrónica ni aplicación móvil nativa.
